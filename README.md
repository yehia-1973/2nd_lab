Layout + component library practice .

2 columns on tablet screens.
3 columns on desktop screens.
Component Library Expansion

Form Elements: Inputs, labels, buttons, and select dropdowns.

Alert / Notification: A styled message box for user feedback.

Ensure text contrast and background colors adapt cleanly to the user’s system preferences.
